# Palette update — October 22, 2026

Home / Hero palette and layout were intentionally left unchanged.

The interior sections now use a coordinated ivory (#F8F4F0), plum (#7A3B6E), ink (#2B2230) palette with section-specific pastel folder colors:
- About: lavender (#F0E2EC)
- Experience: sage (#DFEADD)
- Projects: powder blue (#DCE7F3)
- Research / Publications: peach (#FCE4D4)

Soft pink (#F9E3E6) is reserved for highlights, not used everywhere. Rose, gold and sage are restored to their intended accents, and text contrast is improved.

Edited file: `src/index.css` only. All other source components remain unchanged.

To create a fresh production build: `npm ci && npm run build`. The provided older build ZIP predates this palette change; do not deploy it as the new version.
